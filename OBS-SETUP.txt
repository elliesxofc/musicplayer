moonlit → OBS Studio: show the song you're playing on stream
=============================================================

NEW (desktop app): control OBS from moonlit
-------------------------------------------
go live / end stream, record, switch scenes, show or hide sources, mute and
set volumes, and see the stream's health, all from moonlit's 🎥 button.

  1. in OBS: Tools → WebSocket Server Settings
     → tick "Enable WebSocket server" → Apply
     → "Show Connect Info": note the Server Port (usually 4455) and Password
  2. in moonlit: click the 🎥 (camera) button at the top → settings
     → address: localhost, port: 4455, password: paste it → connect
  3. leave "connect by itself" on: from then on moonlit connects whenever
     OBS is open, and reconnects if OBS restarts.

  while you're live, a red "● LIVE 1:23:45" badge shows at the top of moonlit
  (click it to open the panel). "go live" and "end stream" ask first, so a
  misclick can't start or cut off your stream.

  OBS on a different PC? use that PC's address (e.g. 192.168.1.20) instead of
  localhost, and allow OBS through that PC's firewall.


NEW (desktop app): live "now playing" overlay
---------------------------------------------
a pink card with the cover, song name, artist and a ticking 1:23 / 3:45 bar.
it updates the moment the song changes, and shows "paused" when you pause.

  1. moonlit → sliders button → "obs · now playing" → copy the overlay address
     (usually  http://localhost:4848/overlay )
  2. in OBS: Sources → +  → "Browser" → name it "moonlit overlay" → OK
  3. URL: paste the address. Width 520, Height 180 (card)
     or pick "one line + time" in moonlit first and use Width 900, Height 70
  4. leave "Shutdown source when not visible" OFF → OK

  options in moonlit: style (card with cover / one line + time) and
  "hide while paused". the address changes to match; paste it again in OBS.
  "music bars that move with the song" switches the bars on or off straight
  away, no address change needed. (no bars for Spotify songs: Spotify's sound
  plays in the Spotify app, where moonlit can't hear it.)
  the overlay only works while the moonlit desktop app is open, and only on
  this PC (nobody on the internet can reach it).

the song name format (🎵 Artist - Title, custom, …) applies to the one-line
overlay and to the .txt file below.


NEW (desktop app): Spotify
--------------------------
show what's playing on Spotify in moonlit, with play / pause / skip. while
Spotify is the one playing, the overlay, nowplaying.txt and !nowplaying show the
Spotify song.

on Windows: nothing to set up, works with Spotify Free. just open the Spotify
desktop app on the same PC. moonlit reads the song from Windows' media
controls (the same info Windows shows when you press a media key), and its
buttons press Spotify's own play / pause / skip. on/off: moonlit → sliders →
"spotify" → "show the Spotify app on this PC".

or connect your Spotify account instead (Spotify only allows this when the
account has Premium):
  1. go to https://developer.spotify.com/dashboard, sign in, "Create app"
     (any name and description)
  2. Redirect URIs: add  http://127.0.0.1:4860/callback  and tick "Web API"
  3. save, copy the app's Client ID
  4. moonlit → sliders → "spotify" → "or connect your Spotify account" →
     paste the Client ID → connect spotify, then press "Agree" in the browser


NEW (desktop app): !nowplaying in YouTube chat
----------------------------------------------
viewers type !nowplaying and your bot answers, e.g.
  🎵 now playing: Unknown Brain - War Zone (1:23 / 3:45)

  moonlit → sliders → "chat · !nowplaying":
  - tick "answer !nowplaying in my YouTube chat"
  - your channel, like @yourname: moonlit finds your live stream by itself
    each time you go live (or paste one stream's link)
  - bot login: the same line as YOUTUBE_BOT_CREDENTIALS in the song request
    app. it's saved encrypted on this PC only.


NEW (desktop app): song requests in YouTube chat
-------------------------------------------------
like the song request app, inside moonlit. turn on !nowplaying first (above), then
moonlit → sliders → "chat · !nowplaying" → "take song requests".

  !sr <song name or YouTube link>   request a song
  !queue                            the next 3 requested songs
  !skip                             skip the current song (mods and you)
  !wrongsong                        take back your last request

- !sr looks in your moonlit library first. if the song isn't there (or it's a
  YouTube link), moonlit downloads it, adds it to your library and plays it
  next. a song is only downloaded once.
- YouTube songs can only come from copyright-free channels (NCS, Monstercat,
  TheFatRat, Tobu, … the list is editable), up to 10 minutes long
  (changeable), no live streams. mods follow these rules too, unless you
  switch on "mods and you can request any song".
- blocked words: songs with these words in the title, artist or channel can
  never be requested, by anyone (starts with nazi, hitler, … add your own).
- any song in your library can be requested, so keep songs you wouldn't
  play on stream out of it.
- "remove … songs downloaded for past requests" (settings) cleans up songs
  requested with older versions, which weren't deleted after playing.
- 10 seconds between a viewer's requests, and up to 3 waiting per viewer.
- versions count: "!sr Song (Instrumental)" gets the instrumental (also remix,
  slowed, sped up, nightcore, acoustic, live, cover, karaoke, …), and a plain
  "!sr Song" gets the normal song, not a remix.
- songs downloaded for a request are deleted again (from moonlit and the PC)
  once they've played, or when the request is taken back. songs that were
  already in your library stay. switch: "delete downloaded requests after
  they play".
- requested songs show at the top of your library with "requested by …",
  a ▶ to play one now and an ✕ to remove it.
- don't run the song request app's bot on the same stream at the same time,
  or both would answer !sr and !queue.


the .txt file (works in the website version too)


how it works
------------
moonlit keeps a little text file (nowplaying.txt) updated with the current
song. OBS reads that file and shows it as text in your scene. it updates by
itself every time the song changes.

you need: Chrome or Edge on a computer (Safari / Firefox / phones can't
write files, so the OBS link only works in Chrome or Edge).


1. link the text file in moonlit
---------------------------------
  1. open moonlit in Chrome or Edge
  2. click the sliders button (top right) → "obs · now playing"
  3. click "link nowplaying.txt"
  4. save it somewhere easy to find, e.g.  Documents/moonlit/nowplaying.txt
  5. a pink "OBS" badge appears in the top bar while it's linked

  pick a format there too:
     Artist - Title   (default)
     Title - Artist
     Title only
     ♪ Title — Artist
     now playing: Title by Artist

  optional:
     "clear the text while paused"  → the text disappears when you pause
     "add spacing at the end"       → use this if you add a scroll filter (step 3)


2. add it in OBS Studio
-----------------------
  1. in your scene, Sources → +  → "Text (GDI+)"
     (on Mac / Linux it's "Text (FreeType 2)")
  2. name it "now playing" → OK
  3. tick "Read from file"
  4. Browse → pick the same nowplaying.txt from step 1
  5. choose a font / colour (pink, obviously ♡) → OK

  OBS checks the file every second or so, so the song name follows along.


3. (optional) make it scroll like a ticker
------------------------------------------
  right-click the text source → Filters → +  → "Scroll"
  set Horizontal Speed to ~30, and turn on "add spacing at the end" in moonlit.


4. send the music to the stream without hearing it yourself (virtual cable)
--------------------------------------------------------------------------
the stream gets the music, your speakers stay quiet, and you never have to
mute anything. only moonlit's music goes to the cable. the rest of your PC's
sound stays on your speakers.

  a) install the free VB-CABLE driver
       https://vb-audio.com/Cable/  → download → unzip → right-click
       VBCABLE_Setup_x64.exe → Run as administrator → Install Driver → restart the PC

  b) check your speakers are still the default
       Windows Settings → System → Sound → Output → pick your normal
       speakers / headphones (sometimes Windows switches to the cable after
       installing it)

  c) point moonlit at the cable
       moonlit → sliders button → "sound output"
       → click "find my devices" (Chrome asks for microphone permission; that's
         only so it can show device names. moonlit never records anything) → Allow
       → "play music through": CABLE Input (VB-Audio Virtual Cable)
       moonlit remembers this, even after restarting.

  d) let OBS listen to the cable
       Sources → +  → "Audio Input Capture" → name it "moonlit music" → OK
       → Device: CABLE Output (VB-Audio Virtual Cable) → OK
       (if you used Application Audio Capture or Desktop Audio for moonlit before,
        remove or mute that, so the music isn't on the stream twice)

  e) want to hear it sometimes?
       in OBS: Edit → Advanced Audio Properties → "moonlit music"
       → Audio Monitoring: "Monitor and Output". switch it back to
       "Monitor Off" to go quiet again. the stream isn't affected either way.

  if the cable is ever missing (unplugged / driver removed), moonlit plays
  through your normal speakers instead and tells you so.


every time you come back
------------------------
browsers forget file permission when you close them. the first time you press
play, Chrome/Edge asks "let moonlit edit nowplaying.txt?" → click Allow
(or "Allow on every visit", if it's offered, so it stops asking).
if the badge isn't showing, open the sliders panel and click "reconnect".


troubleshooting
---------------
  - text not changing?  check the OBS badge is showing in moonlit, and that OBS
    points at the exact same file.
  - weird characters (Ã© etc.)?  the file is saved as UTF-8, so pick a font in
    OBS that supports accents and symbols. Segoe UI and Arial both work.
  - want it gone between songs?  turn on "clear the text while paused".
